# linux-vsr: нативный слой аппаратного апскейла видео для linux

linux-vsr — это модульный графический слой и драйверная прослойка для автоматического аппаратного масштабирования и повышения чёткости видео (аналог технологии nvidia rtx video super resolution) на уровне всей системы linux.

работает с любыми браузерами (zen browser, firefox, chromium, chrome, brave) и медиаплеерами (mpv).

проект перехватывает компиляцию opengl/egl-шейдеров на лету и заменяет стандартную билинейную интерполяцию видеотекстуры на алгоритм amd fidelityfx contrast adaptive sharpening (cas) прямо в графическом конвейере видеокарты.

---

## архитектура: модульный монолит

код спроектирован по модульному принципу с разделением ответственности:

- `include/vsr/config.h`, `src/config.c`: загрузка настроек из переменных окружения (`VSR_SHARPNESS`, `VSR_DEBUG`, `VSR_ENABLE`).
- `include/vsr/logger.h`, `src/logger.c`: форматированный вывод диагностических сообщений в терминал.
- `include/vsr/shaders.h`, `src/shaders.c`: генератор шейдерного кода cas с параметрической резкостью.
- `include/vsr/patcher.h`, `src/patcher.c`: синтаксический анализатор шейдеров, склейка чанков и замена вызовов выборки текстур.
- `include/vsr/hook.h`, `src/hook.c`: перехватчик системных функций `glShaderSource`, `glCompileShader` и `eglGetProcAddress`.
- `src/main.c`: жизненный цикл библиотеки (`__attribute__((constructor))` и `destructor`).
- `tests/`: набор модульных тестов для валидации логики патчера и парсера конфигурации.

## конвейер обработки данных (pipeline)

1. **декодирование видеопотока:** аппаратный декодер nvidia nvdec декодирует поток (av1, vp9, h.264) напрямую в видеопамять (vram) в формате nv12 / p010 через `libva-nvidia-driver`.
2. **композитор браузера:** движок webrender (firefox/zen) или skia (chromium) подготавливает шейдер отрисовки видео.
3. **перехват linux-vsr:** библиотека `libvsr.so` перехватывает `glShaderSource`, определяет функцию выборки luma-канала (`sample_yuv`) и внедряет шейдер cas.
4. **выполнение на gpu:** видеокарта в реальном времени масштабирует видео под разрешение экрана или окна (время обработки кадра: **0.02 мс**).
5. **вывод на экран:** готовый кадр без задержек передаётся композитору wayland (gnome-shell).

## сборка

требования:
- gcc или clang;
- make.

сборка библиотеки:
```bash
make -j$(nproc)
```
сборка занимает меньше 0.1 секунды и создаёт файл `libvsr.so`.

## тестирование

проект покрыт набором модульных тестов:
- проверка распознавания целевых видеошейдеров и фильтрации посторонних шейдеров;
- тестирование склейки строковых чанков;
- тестирование замены инструкций выборки текстур;
- тестирование парсинга параметров окружения.

запуск тестов:
```bash
make test
```

пример вывода:
```text
running linux-vsr unit test suite...
  [pass] config module tests
  [pass] patcher module tests
all unit tests completed successfully
```

## запуск

универсальный скрипт запуска автоматически находит браузер и подгружает библиотеку:

```bash
# запуск zen browser
./bin/linux-vsr

# запуск mozilla firefox
./bin/linux-vsr firefox

# запуск chromium
./bin/linux-vsr chromium

# запуск mpv
./bin/linux-vsr mpv https://example.com/video.mp4
```

## конфигурация

| переменная | значение по умолчанию | описание |
|---|---|---|
| `VSR_SHARPNESS` | `0.22` | сила адаптивной резкости (от `0.10` до `0.40`) |
| `VSR_DEBUG` | `1` | вывод отладочных сообщений (`0` для отключения) |
| `VSR_ENABLE` | `1` | включение/отключение обработки |

пример:
```bash
VSR_SHARPNESS=0.30 ./bin/linux-vsr
```
